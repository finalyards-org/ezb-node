# Setting up Rust Rover IDE

Some hints on making it pleasant to work with this repo.

## File associations

`sdkconfig.defaults` is a mere key-value file, with comments. To get syntax highlighting to it, e.g.

- `Settings` > `File types` > `Properties`

	- Add `sdkconfig.defaults` to the file mask

If you don't see `Properties`, make sure a plugin of the same name is installed.

>Alternatively, you may choose to use `INI` file type.


## Plugins

- Makefile
